# CFD 非结构网格生成工作流

本 Skill 决定"当前 CFD 任务走哪条业务路径、需要哪类对象和哪些阶段"。工具审批、对象范围解析、安全确认、错误重试以及 `options`、`tool_params`、`workflow` 的格式，始终遵守基础 system prompt。

## 开始任务前

1. 从实时 MCP 工具列表识别可用工具和 Schema，不凭本文示例虚构工具。
2. 判断用户任务属于下面哪条流程。
3. 读取对应 reference 文件后再规划步骤：
   - CAD 导入、生成和导出网格：`references/cad-to-mesh.md`
   - 水密性处理与自由边检查（含迭代公差调整）：`references/watertight-processing.md`
   - 部件分割（AI 自动识别）：`references/part-segmentation.md`
   - 编辑已有网格：`references/mesh-editing.md`
   - 网格质量检查（含最小角/最大角判断标准）：`references/quality-check.md`
   - 边界条件设置：`references/boundary-conditions.md`
   - 参数建议与属性映射：`references/parameter-reference.md`
   - 飞行器后缘面处理：`references/trailing-edge-processing.md`
   - 关键几何参数计算（MAC/尺寸测量/部件参数表）：`references/geometry-parameters.md`
   - 各向异性网格处理（尺寸计算/网格线分布/后缘处理）：`references/anisotropic-mesh.md`
4. 在 auto 模式下，创建或更新基础协议中的 `phase_plan`，展示完整业务阶段；每次使用相同计划 ID 输出最新状态。
5. 只收集当前阶段缺少的信息，避免一次询问大量后续参数。
6. 每个工具使用实时 Schema 构造参数；手动模式交给参数确认协议，自动模式按基础协议直接执行普通工具。

## 流程路由

### 从 CAD 生成空间网格（主流程）

用户提到导入模型、打开 CAD、开始新项目、生成网格、表面网格、体网格、空间网格、附面层或导出网格时，读取 `references/cad-to-mesh.md`。

主流程的完整阶段链为：
1. CAD 导入与单位设置 → 2. 水密性处理与自由边检查 → 3. 分部件处理 → 4. 碎面合并 → 5. 关键几何参数计算 → 6. 表面网格生成 → 7. 各向异性网格处理（可选）→ 8. 体网格块创建 → 9. 空间网格生成 → 10. 质量检查 → 11. 边界条件设置 → 12. 网格导出

### 水密性处理与自由边检查

用户提到水密性、缝隙、自由边、自由边检查或处理缝隙时，读取 `references/watertight-processing.md`。

核心逻辑：
- 先用默认公差处理 → 检查自由边 → 若存在自由边则公差加大 5 倍重试 → 最多重试 2 次 → 根据自由边位置判断是否处理成功（半模线位置可接受）。

> **预留工具**：`CheckFreeEdges`（自由边检查）— 当前 MCP 工具列表中尚不存在，详见缺失工具报告。在工具就绪前，需提示用户在软件界面中目视检查自由边（蓝色显示）。

### 关键几何参数计算

用户提到 MAC、平均气动弦长、弦长、翼根弦长、翼尖弦长、机翼展长、半展长、特征长度、机身长度或尺寸测量时，读取 `references/geometry-parameters.md`。

核心逻辑：
- 参数优先级：用户输入 > AI 测量 > 文档默认值。
- MAC 公式：MAC = (2/3) × C_root × [(1 + λ + λ²) / (1 + λ)]，其中 λ = C_tip / C_root。
- 部件网格参数表基于 MAC 推导：机头 2%×MAC、机身 4%×MAC、机翼 ≤3%×当地弦长等。

> **预留工具**：`MeasureDistance`（两点距离测量）和 `GetPointOnSurface`（获取数模点坐标）— 当前 MCP 工具列表中尚不存在，详见缺失工具报告。在工具就绪前，优先向用户询问几何参数，或使用 `GetModelBox()` 获取特征长度。

### 分部件处理

用户提到部件分割、分割部件、自动分割、识别部件时，读取 `references/part-segmentation.md`。

翼身组合体标准划分：机头、机尾、机翼（上翼面/下翼面/翼稍面/后缘面）、垂尾、平尾。若用户导入模型存在外场，需将外场单独设置部件。

### 碎面合并

用户提到碎面、合并面、合并碎面时，使用碎面处理工具（`UGSurfaceProcessing`，type=-1 合并）或网格面合并工具（`UGJoinDomain`）。

原则：机头、机尾数模面尽量保证为一个；机翼一般分为上翼面、下翼面、翼稍面、后缘面；其他处尽量保证数模面平整，仅保证关键特征。

### 表面网格生成

用户提到表面网格、生成面网格时，使用 `UGSur` 或 `GenerateSurMeshBySpitAssemblyGroupProperty`。

参数来源：优先使用 `GetGenerateSurMeshDefaultParam()` 获取默认参数，再根据几何参数计算结果调整各部件的目标尺寸和最小尺寸。

**阶段闸门（重要）**：表面网格生成成功后，**下一步必须执行体网格块创建**。严禁直接在表面网格生成完成后跳到空间网格生成（`UGUGSp`）。先引导用户进行体网格块创建，之后再进入空间网格生成步骤。

### 各向异性网格处理（可选）

用户提到各向异性、网格线分布、前缘加密、后缘加密、翼梢加密或减少网格数量时，读取 `references/anisotropic-mesh.md`。

核心逻辑：
- 适用位置：机翼前缘、后缘、翼梢、翼身结合处及曲率较大的地方。
- 尺寸计算：前缘/后缘 0.1%×当地弦长，翼根/翼梢 0.1%×半展长。
- 参数：增长率 1.2，层数 50。
- 关键原则：各向异性只控制内部点分布，不更改边界分布；需将网格线分布与各向异性分布匹配。
- 通过 `UGReDimensionConfigDistribution` / `UGReDimensionSmoothDistribution` 等工具实现。

### 编辑已有网格

用户提到移动、平移、旋转、缩放、镜像、删除、移除、清理、合并、分割、拆分、调整或编辑网格时，读取 `references/mesh-editing.md`。

### 网格质量检查

用户提到检查质量、网格质量、质量报告、点数分布、加密或稀疏时，读取 `references/quality-check.md`。

判断标准：
- 面网格：除去各向异性单元处，最小角应大于 10°。
- 体网格：最大角不大于 178°算质量好；严格禁止存在 179.9°单元。

### 飞行器后缘面处理

用户提到后缘面处理、后缘网格、trailing edge、后缘分布、翼梢交线时，读取 `references/trailing-edge-processing.md`。

后缘属于细长矩形形状，需保证对边的点数及分布相同。详见 `references/trailing-edge-processing.md`。

### 边界条件

用户提到边界条件、BC、流入、流出、壁面、远场或对称面时，读取 `references/boundary-conditions.md`。

一般分类：外场、物面、对称。物面可根据分部件情况分成多个物面。

### 空间网格生成

用户提到空间网格、体网格、附面层、外场或体创建时，读取 `references/cad-to-mesh.md` 第 5 节。

场景分类：
- 场景一：外场面存在 + 全模 → 外场属性 + 物面属性，法向量向外。
- 场景二：外场面存在 + 半模 → 外场属性 + 物面属性 + 对称属性，法向量向外。
- 场景三：不存在外场 + 全模 → 先通过体创建生成外场。
- 场景四：不存在外场 + 半模 → 先设置半模边界线 → 体创建生成外场 → 生成空间网格。

外场大小规则：
- 亚音速（0-1 马赫）：模型特征长度的 20 倍，外场形状一般给球形。
- 超音速（>1 马赫）：大于 1.5 倍特征长度，外场形状一般给弓形。

空间网格参数：
- 附面层首层高度：根据 y+、雷诺数、参考长度计算。y+ 默认为 1；雷诺数默认取 1.5×10⁷；参考长度取平均气动弦长。
- 增长率：1.2（默认）。
- 层数：40 层（默认）。
- 扩散因子：粗网格 0.5 / 中等 0.8 / 细网格 0.98。
- 单元类型：四面体（默认）。

> **预留工具**：`CalculateFirstLayerHeight`（附面层首层高度计算）— 当前 MCP 工具列表中尚不存在，详见缺失工具报告。在工具就绪前，根据上述公式由 AI 计算或向用户询问。

## 知识库参数体系

以下参数体系来自非结构网格生成知识库，作为参数建议使用。只要实时 MCP 提供默认参数查询工具，就以查询结果为准。

### 部件网格参数表

| 部件名称 | 目标尺寸 | 最小尺寸 | 曲率自适应角度 |
|---|---|---|---|
| 机头 | 2% × MAC | 目标尺寸 × 1/10 | 默认 10° |
| 机尾 | 2% × MAC | 目标尺寸 × 1/10 | 默认 10° |
| 机身 | 4% × MAC | 目标尺寸 × 1/10 | 默认 10° |
| 机翼 | ≤ 3% × 当地弦长，默认用 2% × 当地弦长 | 目标尺寸 × 1/10 | 默认 10° |
| 其他 | 4% × MAC | 目标尺寸 × 1/10 | 默认 10° |
| 外场（若存在） | 根据不同场景计算 | 目标尺寸 × 1/10 | 默认 10° |

多段翼可参考机翼的要求分布表面网格。主翼、襟翼、副翼、缝翼、导流片等的前后缘附近的表面网格间距取 0.1% 平均气动弦长。

### 各向异性尺寸计算表

| 位置 | 尺寸计算公式 |
|---|---|
| 机翼前缘 | 0.1% × 当地弦长 |
| 机翼后缘 | 0.1% × 当地弦长 |
| 翼根尺寸 | 0.1% × 半展长 |
| 翼梢尺寸 | 0.1% × 半展长 |

### MAC 计算公式

1. 计算尖根比 λ = C_tip / C_root
2. 计算 MAC = (2/3) × C_root × [(1 + λ + λ²) / (1 + λ)]

参数来源优先级：用户输入 > AI 测量 > 文档默认值。

## 阶段依赖规则

- `phase_plan`（仅 auto 模式）仅展示动态业务阶段，不代表工具已经执行；必须由实际返回结果更新状态。
- 参数全部已知且步骤之间没有动态数据依赖时，可以输出静态 workflow。
- 后一步参数依赖前一步返回值时，拆成多个阶段：先执行并读取结果，再生成下一次 `tool_params`。
- 导入、网格生成、对象查询或属性查询失败时，不继续依赖它的后续步骤。
- 领域参考值只能作为建议；存在默认参数查询工具时，以实时查询结果为准。
- **水密性处理迭代规则**：处理失败时公差加大 5 倍重试，最多重试 2 次；两次仍无效则停止迭代，提示用户模型可能存在缝隙、穿插、孔洞等错误。
- **几何参数依赖规则**：部件网格参数表和各向异性尺寸均依赖 MAC 计算；MAC 计算依赖翼根弦长、翼尖弦长、机翼展长测量；若用户直接提供这些参数则跳过测量步骤。
- **表面网格前置依赖**：表面网格生成前必须完成水密性处理（含自由边检查通过）和分部件处理。
- **空间网格前置依赖**：空间网格生成前必须完成表面网格生成和体网格块创建；半模场景需先设置半模边界线。
- **表面网格→体网格块闸门**：表面网格生成成功后，必须停下来执行体网格块创建，不得跳过该步骤直接调用空间网格生成工具（`UGUGSp`）。等待体网格块创建完成后再继续。体网格块创建完成后，manual 模式通过 `options` 询问用户是否需要创建附面层/设定外场；auto 模式根据用户原始目标自动判断，然后再生成空间网格。
- **各向异性可选性**：若用户对网格数量没有要求，可不做各向异性处理步骤。
- **质量检查标准**：面网格最小角 > 10°（各向异性单元除外）；体网格最大角 ≤ 178°，禁止 179.9° 单元。

## 输出规范

- 保存工程：保存工程文件，名字默认为模型名字，路径默认为模型路径。
- 网格导出格式：CGNS 格式，名字默认为模型名字，路径默认为模型路径。

## 完成标准

完成当前用户明确要求的阶段后，简要报告实际工具结果。manual 模式提供下一步可执行的结构化选项；auto 模式根据用户原始目标自动推进，仅在不可逆高影响操作前使用 `options` 确认。不得把尚未执行的阶段描述为已完成。
