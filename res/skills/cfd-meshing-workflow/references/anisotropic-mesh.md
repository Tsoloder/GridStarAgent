# 各向异性网格处理

## 1. 基本说明

### 1.1 作用
减少网格数量。

### 1.2 适用场景
若用户对网格数量没有要求，可不做此步骤。

### 1.3 适用位置
- 机翼前缘
- 机翼后缘
- 翼梢
- 翼身结合处
- 曲率较大的地方

若用户标注了需要哪些位置做各向异性，则以用户的输入为准。

## 2. 各向异性尺寸计算

| 位置 | 尺寸计算公式 | 计算示例（MAC≈134.75） |
|---|---|---|
| 机翼前缘 | 0.1% × 当地弦长 | ≈ 0.134 |
| 机翼后缘 | 0.1% × 当地弦长 | ≈ 0.134 |
| 翼根尺寸 | 0.1% × 半展长 = 0.1% × 1/2 b | ≈ 0.268 |
| 翼梢尺寸 | 0.1% × 半展长 = 0.1% × 1/2 b | ≈ 0.268 |

## 3. 各向异性参数设置

| 参数项 | 默认值 | 说明 |
|---|---|---|
| 首层高度 | 根据具体位置尺寸确定 | 见尺寸计算表 |
| 增长率 | 1.2 | 默认参数 |
| 层数 | 50 | 一般来说 50 层较合适 |

## 4. 网格线分布调整原则

### 4.1 核心思想
各向异性网格只控制内部点分布，不更改边界分布。

### 4.2 匹配原则
需将网格线分布与各向异性分布匹配。

### 4.3 具体分布规则

| 位置 | 分布规则 |
|---|---|
| 翼梢、翼身结合处网格线靠近前缘段 | 首层与机翼前缘各向异性首层一致，增长率 1.2 |
| 中间值控制 | 一般与翼面尺寸一致 |
| 翼根/翼梢分布值 | 0.1% × 1/2 b |
| 支架段（若存在） | 保证平滑分布 |

## 5. 后缘处理

后缘属于细长矩形形状，需将网格类型调整为狭长面（`GenerateLongAndNarrowFaceGrid`），狭长面需保证对边的点数及分布相同。完整流程参见 `references/trailing-edge-processing.md`。

## 6. 工具调用流程

### 6.1 设置各向异性网格线分布

1. 确定需要各向异性的位置（前缘、后缘、翼梢等）。
2. 计算各位置的尺寸（见尺寸计算表）。
3. 获取对应位置的网格线 ID。
4. 使用 `UGReDimensionConfigDistribution` 设置分布参数：
   - `headspace`：首端间距（各向异性首层高度）
   - `tailspace`：尾端间距
   - `headRate`：首端增长率（1.2）
   - `headLayer`：首端层数（50）
   - `disFunc`：分布类型（0=双曲正切）
5. 如需平滑过渡，使用 `UGReDimensionSmoothDistribution`。
6. 如需匹配对边分布，使用 `UGReDimensionMatch`。

### 6.2 注意事项
- 各向异性只控制内部点分布，不更改边界分布。
- 需将网格线分布与各向异性分布匹配。
- 狭长面需保证对边的点数及分布相同。
