# 编辑已有网格

## 路由

manual 模式先通过 `options` 确认操作类型；auto 模式根据用户原始目标自动判断：

- 变换：平移、旋转、缩放、镜像；
- 删除；
- 合并或分割；
- 其他实时 MCP 明确支持的编辑操作。

## 执行步骤

1. 根据目标工具确定对象类型。
2. 按基础对象范围选择规则获取全部对象或当前选中对象的 ID。
3. 如果工具需要端点、中心、法向或其他几何信息，先调用查询工具获取。
4. 后续参数依赖查询结果时，等待查询完成后再生成参数确认。
5. manual 模式使用 `tool_params` 展示对象类型、数量、ID 和变换值等参数；auto 模式直接执行。
6. 用户确认后执行编辑工具。
7. 删除、合并、分割和批量变换必须清楚显示影响范围。
8. 等待工具返回后报告实际结果；失败时停止后续操作。
