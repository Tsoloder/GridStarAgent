# 水密性处理与自由边检查

## 1. 获取公差

1. 从 MCP 工具中识别公差查询工具 `GetDealWatertightTolenrance`。
2. 调用并等待结果。
3. 从返回值提取公差值；手动模式使用 `tool_params` 显示实际值并确认，自动模式直接采用查询值。不得提前猜测或硬编码公差。

## 2. 执行水密性处理

1. 调用 `DealWatertight(tolenrance)` 并等待结果。
2. 返回 JSON 字符串，包含以下字段：

   | 字段 | 类型 | 说明 |
   |---|---|---|
   | `status` | string | `"true"` 成功，`"false"` 失败 |
   | `free_edge_count` | int | 剩余自由边总数 |
   | `free_edge_pairs_in_tol` | int | 公差内可合并的自由边对数 |
   | `has_free_edges` | bool | 是否存在自由边 |

   示例返回值：
   ```json
   {"status":"true","free_edge_count":0,"free_edge_pairs_in_tol":0,"has_free_edges":false}
   ```

3. `status` 为 `"false"` 时停止，不得继续后续步骤。
4. `has_free_edges` 直接指示是否存在自由边，无需额外调用其他工具。

## 3. 自由边检查（迭代逻辑）

### 3.1 检查流程

`DealWatertight` 返回结果中的 `has_free_edges` 和 `free_edge_count` 字段可直接用于判断自由边情况，无需单独的 `CheckFreeEdges` 工具。

```
默认公差处理 → 检查自由边
  ├─ 不存在自由边 → 处理成功，进入下一流程
  ├─ 存在自由边 → 公差 × 5 重新处理 → 检查自由边
  │    ├─ 不存在自由边 → 处理成功
  │    └─ 仍存在自由边 → 公差 × 5 重新处理（第二次重试）→ 检查自由边
  │         ├─ 不存在自由边 → 处理成功
  │         └─ 仍存在自由边 → 停止迭代，判断自由边位置
  └─ 判断自由边位置
       ├─ 自由边位置全在半模线 → 模型处理完毕，进入下一流程
       └─ 自由边位置在其他位置 → 提示用户模型可能存在缝隙、穿插、孔洞等错误
```

### 3.2 失败判断规则

- 公差加大两次 5 倍仍然存在自由边 → 不再增加公差。
- 根据自由边位置判断处理结果：
  - 自由边位置全在半模线 → 模型处理完毕。
  - 自由边位置在其他位置 → 模型可能还存在缝隙、穿插、孔洞等模型错误。

### 3.3 半模线判断

- 半模情况下也存在自由边，需通过查看自由边位置判断。
- 软件将自由边蓝色显示，用户可目视确认。

## 4. 处理结果通知

- **处理成功**（不存在自由边 或 自由边全在半模线）：
  - 输出"模型处理完毕"，自动进入下一流程。

- **处理失败**（自由边在其他位置）：
  - 提示用户"模型可能还存在缝隙、穿插、孔洞等模型错误"。
  - 让用户自行手动处理。
  - 手动处理完毕后，让用户点击"继续执行"按钮再进入下一流程。

## 5. 工具调用顺序

强制顺序：`GetDealWatertightTolenrance` → `DealWatertight`（返回 JSON 含自由边信息）→ （根据 `has_free_edges` 迭代或继续）

- `has_free_edges` 为 `false` → 处理成功，进入下一流程。
- `has_free_edges` 为 `true` → 公差 × 5 重试（最多 2 次）。
- 重试 2 次后仍有自由边 → 需通过软件界面目视确认自由边位置（半模线可接受，其他位置提示模型错误）。
