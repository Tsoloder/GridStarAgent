# CFD 参数与属性参考

这些值仅用于提出建议。只要实时 MCP 提供默认参数、可选值或属性查询工具，就以查询结果为准。

## 参数建议

| 参数 | 参考值 | 说明 |
|---|---:|---|
| CAD 导入角度 | 10.0 | 曲率自适应角度 |
| 表面网格目标尺寸 | 0.05 | 应优先通过默认参数工具获取 |
| 空间网格层数 | 40 | 附面层层数参考 |
| 增长率 | 1.2 | 空间网格增长率参考 |

## 边界条件属性参考

| 值 | 含义 |
|---:|---|
| -10 | 无边界条件 |
| 3 | 无粘固壁 |
| 4 | 粘性固壁 |
| 7 | 远场 |
| 8 | 对称 |
| 10 | 流入 |
| 11 | 流出 |
| 12 | 喷流入口 |
| 13 | 喷流出口 |

如果工业软件实时返回的映射与本表不一致，必须采用实时返回值，并向用户说明当前软件版本的属性定义。
