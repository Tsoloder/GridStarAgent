# 边界条件设置

## 1. 确认操作场景

manual 模式使用 `options` 询问；auto 模式根据用户原始目标自动判断：

- **场景 A：基于分部件自动初始化** — 已有分部件属性时，按分部件分组自动创建边界条件组并挂载网格面，属性统一设为无边界条件。适用于网格生成完成后的首次边界条件铺底。
- **场景 B：手动新建边界条件组** — 用户指定组名、属性和对象范围。
- **场景 C：编辑已有边界条件组** — 修改已有组的属性或对象范围。

## 2. 场景 A：基于分部件自动初始化

### 前置条件

已通过部件分割（`ProcessWithServer` 或 `SegmentPartDirect`）生成分部件分组，且表面网格已生成。

### 步骤 1：获取分部件分组

调用 `GetAllSpitAssemblyGroupProperty()` 获取所有分部件分组的属性信息。返回值为 JSON 数组，每个元素以分组名称为键，包含 `line`（线组）和 `domain`（面组）子结构。

从返回结果中提取所有分组名称，作为后续遍历的依据。

### 步骤 2：创建边界条件组

遍历每个分部件分组名称，调用 `BorderConditionAddGroup` 创建对应的边界条件组：

| 参数 | 取值规则 |
|---|---|
| `name` | 直接使用分部件分组名称（如 `fuselage`、`jiyi_wing_upper_surface`） |
| `groupID` | 从 100 开始递增，每个分组 +1（100, 101, 102, …） |
| `colorNumber` | 按分组顺序循环取 0-5（第 1 个组取 0，第 2 个取 1，… 第 7 个回到 0） |

manual 模式使用 `tool_params` 展示完整分组列表（组名、ID、颜色）；auto 模式直接执行。

### 步骤 3：获取分部件分组对应的网格面

对每个分部件分组，调用 `GetSpliteAssemlyDomains(groupName)` 获取该分组下超面对应的网格面 ID 集合。

返回格式为 `{"domains":[4,31,55]}`。若返回 `"false"` 或 domains 为空，跳过该分组并记录警告。

> **注意**：分部件信息存在于超面对象上，网格面对象本身不持有分部件信息，必须通过此工具间接获取。

### 步骤 4：将网格面设置到边界条件组

对每个分组，调用 `BorderConditionSaveDataToDomain` 将步骤 3 获取的网格面挂载到步骤 2 创建的边界条件组：

| 参数 | 取值规则 |
|---|---|
| `domainIDs` | 步骤 3 获取的网格面 ID，逗号分隔（如 `"4,31,55"`） |
| `name` | 与步骤 2 创建的边界条件组名一致 |
| `groupID` | 与步骤 2 创建的边界条件组 ID 一致（100, 101, …） |
| `property` | 统一设为 `-10`（无边界条件） |

### 步骤 5：报告结果

汇总报告：创建了多少个边界条件组、每组挂载了多少网格面、是否有分组因无网格面被跳过。

初始化完成后，用户可进入场景 C 逐组编辑属性（如将外场设为远场、物面设为粘性固壁等）。

## 3. 场景 B：手动新建边界条件组

### 获取组和属性

1. 从实时 MCP 工具获取现有组信息或创建组所需 Schema。
2. 获取工业软件当前支持的边界条件属性。
3. 属性查询结果是事实来源；参考映射只用于辅助解释。

### 选择目标对象

边界条件通常作用于网格面。明确目标类型后，按照基础对象范围选择规则获取全部对象或当前选中对象的 ID。

### 确认与应用

1. manual 模式使用 `tool_params` 显示组名、属性、对象类型、数量和 ID；auto 模式直接执行。
2. 调用 `BorderConditionAddGroup` 创建组，再调用 `BorderConditionSaveDataToDomain` 设置网格面。
3. 等待返回后报告实际结果。

## 4. 场景 C：编辑已有边界条件组

1. 获取现有边界条件组列表和属性。
2. manual 模式使用 `tool_params` 显示将被修改的组名、当前属性、目标属性和对象范围；auto 模式直接执行。
3. 修改属性使用 `BorderConditioConfigProperty`（`number=2` 修改 property）。
4. 追加或替换网格面使用 `BorderConditionSaveDataToDomain`。
5. 等待返回后报告实际结果。

## 5. 属性参考

| property 值 | 含义 |
|---|---|
| -10 | 无边界条件 |
| 1 | 传值 |
| 2 | 对接 |
| 3 | 无粘固壁 |
| 4 | 粘性固壁 |
| 7 | 远场 |
| 8 | 对称 |
| 10 | 流入 |
| 11 | 流出 |
| 12 | 喷流入口 |
| 13 | 喷流出口 |

一般分类：外场→远场(7)、物面→粘性固壁(4)、对称面→对称(8)、流入面→流入(10)、流出面→流出(11)。
