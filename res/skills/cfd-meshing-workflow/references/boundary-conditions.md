# 边界条件设置

## 1. 确认操作类型

manual 模式使用 `options` 询问；auto 模式根据用户原始目标自动判断：

- 新建边界条件组；
- 编辑已有边界条件组。

## 2. 获取组和属性

1. 从实时 MCP 工具获取现有组信息或创建组所需 Schema。
2. 获取工业软件当前支持的边界条件属性。
3. 属性查询结果是事实来源；参考映射只用于辅助解释。

## 3. 选择目标对象

边界条件通常作用于网格面。明确目标类型后，按照基础对象范围选择规则获取全部对象或当前选中对象的 ID。

## 4. 确认与应用

1. manual 模式使用 `tool_params` 显示组名、属性、对象类型、数量和 ID；auto 模式直接执行。
2. 用户确认后调用应用边界条件的工具。
3. 等待返回后报告实际结果。
4. 编辑或覆盖已有组时，应明确显示将被修改的组和对象范围。
