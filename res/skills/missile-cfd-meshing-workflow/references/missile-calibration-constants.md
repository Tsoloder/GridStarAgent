## §2 🔴 尺寸取值（`GetMissileDimensions` 接口返回即权威，单位 mm）

> 🔴 **2026-10-14 用户裁定：一律直接用接口返回值**。
> 接口**返回的就是毫米（mm）**，直接用，**不要 ×1000**。
> 🔴 **2026-10-17 更新：尺寸恢复为几何实算**——由分割流水线 `ClassifyMissile` 第 10 步
> `CalculateDimensions()` 从点云与分割结果算出并缓存，`GetMissileDimensions()` 读同一份缓存。

> skill 侧**始终不记任何数值**。

### 2.0 尺寸字段清单（全部取接口返回值，**不记数值**）

> 🔴 **本文不列任何具体数值**：数值由分割实算得出，随模型变化。
> 运行一律取接口返回值，skill 侧记数值只会造成"改一处漏一处"。

| 量 | 字段 | 用途 |
|---|---|---|
| 弹径 D | `body_diameter` | 头锥/弹体交接处口径。🔴 **球头公式与各向异性用此值** |
| 表面网格有效弹径 | `body_diameter_surface` | 🔴 **表面网格专用**（球头公式**除外**）。规则见 §2.2.1 |
| 弹尾口径 | `body_diameter_tail` | 失配判据来源；弹尾相关尺寸 |
| 球头半径 R | `nose_radius` | 球头尺寸 `min(0.01×D, 0.25×R)`；`>0` = 球头，`==0` = 尖头（M3） |
| 全弹长 | `fuselage_length` | 弓形外场长度（`1.5×`）与另外 3 位（`1.2×`）的基准 |
| 🔴 **弹翼（按对）** | **`wings[]`** | **数组，下标 = 对数−1**；每项 `root_chord` / `tip_chord` / `half_span` / **`thickness`**。见 §2.1 |
| ⌐ 翼根弦长 C_root(N) | `wings[N−1].root_chord` | 表面网格尺寸基准（`0.02×`）/ 各向异性**中间值**基准 |
| ⌐ 翼梢弦长 C_tip(N) | `wings[N−1].tip_chord` | 🔴 **按翼型分叉**（M2 / §2.2.2） |
| ⌐ 🔴 **翼厚度 T(N)** | `wings[N−1].thickness` | **各向异性首层高度/端间距基准**（`0.1×`，2026-10-22 起）；= 该对翼根部**尾缘带沿厚度方向的跨度** |
| ⌐ 半翼展 b/2(N) | `wings[N−1].half_span` | 第 N 对展向分布插值跨度（🔴 仅报告，后端不参与尺寸计算） |
| ⌐ 第 1 对便捷标量键 | `wing_root_chord` / **`wing_thickness`** | = `wings[0]`，同源；多对翼一律走 `wings` 数组。🔴 旧标量键 `wing_tip_chord` / `wing_half_span` **已不再产出**（`tip_chord`/`half_span` 只在 `wings[]` 内） |

#### 2.1 🔴 多对弹翼：`wings` 数组（2026-10-16 新增）

> 🔴 **2026-10-17 更新**：`wings` 数组由分割实算写入——长度 = **分割识别出的翼对数**（按 `wing*N` 组名的 N 推出），**与模型实际对数一致**，不再是"手填几对就是几对"。

- **模型实际对数由分组探测**（`wingSideSurface1` ~ `wingSideSurface3`，见 `missile-segmentation.md`），`wings` 数组长度应与之一致。
- **取不到的对回退到第 1 对**（后端对缺项补位）—— 用作兜底，正常情况下不会命中。
- 🔴 **表面网格与各向异性都必须按对取值**，不得用某一对的 C_root/C_tip 代跑其他对（各对弦长可差 5 倍以上）。翼性子面组名末位数字即 N（`wingSideSurface2` → `wings[1]`）。
- 🔴 **`half_span` 仅报告字段**：后端不参与任何尺寸计算（`CalcWingPairDimensions` 只读 root/tip 算 MAC），可留 0。

#### 2.2.1 🔴 表面网格有效弹径 `body_diameter_surface`（2026-10-14 新增）

> 用户裁定（原文）："表面网格生成中，导弹的几何参数弹径和弹尾口径差距大的时候，表面网格生成**除了球头公式**，弹径 D 就用弹尾口径替代来生成更合理。**球头的网格生成还是用原本的弹径和球头半径参数公式计算**。"

| 情形 | 表面网格用哪个口径 | 球头公式用哪个 |
|------|------------------|---------------|
| `\|D − D_tail\| > 0.7 × D_tail`（失配 >70%，2026-10-16 由 20% 改定）| 🔴 **弹尾口径 `body_diameter_tail`** | 🔴 **仍用原始 D + R**（不受影响） |
| 差异 ≤70%，或尾口径缺失/非法 | 弹径 D | D + R |

- 🔴 **球头公式为例外，不得套用**：球头部件仍用**原始 `body_diameter` + `nose_radius`**，即 `min(0.01×D, 0.25×R)`（尖头为 `0.005×D`）。

#### 2.2.2 🔴 C_tip 按翼型分叉（原 #4 规则保留，无条件生效）

- **三角翼**（无 `wingTipN`，M2）：C_tip ≈ 0 属正常，**禁止把 0 代入公式**；凡 `0.02×当地弦长` 的"梢部端"**中间值**一律**钳制到该对 C_root 计算值**（`0.02×C_root(N)`，按 `wings[N−1].root_chord` 现算）。🔴 **各向异性的首层高度/端间距不再涉及弦长**——一律 `0.1×该对厚度`，与翼型无关。
- **梯形翼**（有 `wingTipN`）：按 `wings[N−1].tip_chord` 正常使用，**不钳制**。
- 🔴 该规则**无条件生效**，即使接口 C_tip 返回 0 也不得回退到 0 代入。
- 🔴 **按对生效**：钳制目标是**该对**的 C_root，不得用第 1 对的 C_root 替其他对钳制。

> 🔴 **一站式返回后不做核验**：`MissileWingAnisoProcessWingAnisotropy()` 与 `MissileBodyAnisoProcessBodyAnisotropy()` 返回 `status="success"` 即为该阶段结束，**直接进入下一阶段**——不读 `step1_dimensions` / `step2_classify` / `step3_distribution` / `step4_aniso_line_groups` / `step5_aniso_domains` 做尺寸正值、`body_diameter_surface` 自洽性、各对 `root_chord`/`thickness`、窄面增长率、首层高度的任何比对。§2.2.1 / §2.2.2 / §2.3 的规则供**表面网格阶段**取口径，以及 `status="failed"` 后的**分步回退**取值使用。详见 `missile-anisotropic-mesh.md` §「判定与路由」。
>
> ✅ **一站式工具现状（2026-10-22 替换）**：`MissileWingAnisoProcessWingAnisotropy()`（无参数，后端 `MissileWingAnisotropicProcessor`）。🔴 **弹翼尺寸（根弦长 / 厚度）按对读 `SPIDER::Data` 的数组**（`m_wingRootChords[N−1]` / `m_wingThicknesses[N−1]`，由 `GetMissileDimensions` 接口写回）——旧文档所述「直读尺寸缓存 `wings`、不经 `SPIDER::Data` 中转」（`GetWingPairDims`）**已作废**；弹体尺寸（D / 尾口径 / R / 全弹长）读 `SPIDER::Data`，来源相同。🔴 **未调 `GetMissileDimensions` → 按对数组为空 → 该工具直接返 `failed`**。反向要求：**各向异性阶段之前必须先完成分割并调用 `GetMissileDimensions`**。
> ⚠️ **旧一站式 `MissileAnisoProcessMissileAnisotropy`（`MissileAnisotropicProcessor`）已随本次替换弃用**，含其第 7 步弹尾加密；**新工具不含弹尾加密**，弹尾由后续独立工具处理。

#### 2.3 🔴 弹身各向异性尺寸基准（2026-10-26 新增，`MissileBodyAnisoProcessBodyAnisotropy`）

> 🔴 **弹身与弹翼是两个独立的一站式工具，都要调用，且顺序固定：先弹身、后弹翼。**
> 弹身工具只处理 `fuselage` 组，**不读弹翼按对数组**、也**不写弹翼参数**。

| 量 | 值 | 用途 |
|---|---|---|
| 弹身各向异性尺寸唯一来源 | 🔴 `SPIDER::Data::m_bodyDiameterTail`（弹尾口径，mm） | 全部中间值与首层兜底 |
| 中间值（A / B 类线） | `0.05 × 弹尾口径` | `UGReDimensionSmoothDistribution` 中间值 |
| 中间值（E 类线） | `0.05 × 弹尾口径` | 与弹头共点那批**同比例** |
| 增长率 / 层数 | **1.2 / 50**（两组各向异性线组统一） | 组1 `bodyTailJunction` / 组2 `bodyNoseJunction` |

> 🔴 **A/B 与 E 的中间值比例相同（都是 `0.05 × 弹尾口径`）**——2026-10-26 由旧的
> `0.025×`（A/B）与 `0.04×`（E）统一改为 `0.05×`，**旧比例已作废**。

**弹身网格线分类（"属于弹身"即 `fuselage` 组，五类 A~E）**：

| 类 | 定义 | 分布设置 | 各向异性归属 |
|---|---|---|---|
| **A** | 与【弹尾】和【弹翼后缘】同时共点的弹身线 | 首尾端间距 = 共点弹翼后缘线的端间距；增长 1.2/1.2、中间值 `0.05×尾口径` | 组1 |
| **B** | 与【弹翼前缘】和【弹翼后缘】同时共点的弹身线 | 前缘相邻端取前缘线端间距、后缘相邻端取后缘线端间距；同上中间值 | 组1 |
| **C** | 弹尾 ∩ 弹身 交线 | 不经步骤 3（仅作组1 的线、面来源） | 🔴 **组1** |
| **D** | 弹头 ∩ 弹身 交线 | 不经步骤 3；其**首尾端间距平均值**即组2 首层高度 | 🔴 **组2** |
| **E** | 与【弹头】共点的弹身线 | 共点端 = D 的首尾端间距平均值、**另一端不变**；增长 1.2/1.2、中间值 `0.05×尾口径` | 组2 面集内 |

**两个各向异性线组（`UGNewANisoDomain` type=1，增长率 1.2、层数 50）**：

| 组名 | 线 | 面 | 首层高度 |
|---|---|---|---|
| `bodyTailJunction` | A ∪ B ∪ C | 与弹尾相交的弹身面 + 弹尾面 | A 类线端间距 |
| `bodyNoseJunction` | D | 弹头面 + **其余未做各向异性处理的弹身面** | D 类线首尾端间距平均值 |

> 🔴 首层高度取不到正值时**兜底退 `0.05 × 弹尾口径`**（避免 0 首层），不报错。
> 🔴 **弹尾口径为 0 → 步骤 1 守卫 `failed`**（`GetMissileDimensions` 未调）。
> ⚠️ 弹身工具**不含弹尾独立加密**——它做的是【弹尾∩弹身】与【弹头∩弹身】两处**结合处**各向异性，
> 与旧一站式 step6 的"弹尾加密"不是同一件事。

## §4 幽灵块（已删除对象残留 ID）

- **现象**：`DeleteBlock(1)` 后 `GetAllObjectByType(7)` 仍返回 `[1,2]`（块 1 残留引用）。
- **杀伤**：未过滤时 `UGUGSp` 连续 `false`；`GetAllObjectByType(6)` 的面/线列表也可能含幽灵 ID。
- **对策（按优先级）**：
  1. **存活台账（首选，零额外调用）**：体创建成功记存活块 ID、`DeleteBlock` 记已删；拼接 ids 只取台账。
  2. **台账缺失时 → 剔除策略**：`GetAllObjectByType(7)` 结果与存活台账对比取差集，以存活台账为准。
  > ⚠️ **严禁用 `GetConnectorsByDomains` 验证块 ID**（面→线查询，不接受体块 ID，会把合法块全剔除、ids 传空）——两种策略下都适用。
- 详细排查法：`missile-mesh-sealing-check.md`（含面/线级幽灵 ID 过滤）。

## 使用纪律

1. 本清单只解决**已知卡点**，不豁免任何硬闸门（水密/顺序/质量等仍必须执行）。🔴 **碎面合并（阶段 4）为条件触发**——用户提到碎面/合并面/合并碎面时才执行，未提及则标记 `skipped`+`note`；仅当表面网格出现"不封闭 / 异常偏密"时回头补做。
2. 换弹体（几何尺寸显著变化）：#5 方向位按弹头指向重取、#6 `centerCoor` 沿用默认（**都无需型号常数**）；🔴 **尺寸一律随几何实算走**——新弹体重新跑 `ClassifyMissile` 即由后端 `CalculateDimensions()` 实算新尺寸，接口自动返回，skill 无需改动、无常数可改。
3. 后端修复后改回：**改回即删行/改行，不留并存**。
4. 🔴 **单位唯一纪律**：接口返 **mm**，直接传参，**任何地方都不得再 ×1000**。
